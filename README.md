Academic project focused on the design and implementation of a relational database 
for an inventory management system of a fictional construction materials company.

The project involved database analysis, entity relationship modeling, schema design, 
table creation, and the implementation of SQL queries to support inventory operations. 
The database was structured to efficiently store, organize, and manage product 
information while maintaining data integrity and consistency.

Technologies Used:
MySQL
SQL
Responsibilities
Requirements analysis
Entity-Relationship (ER) modeling
Relational database design
Table creation and normalization
SQL query development
Database documentation
Key Features
Structured product inventory storage
Relational data management
Data integrity enforcement
Support for CRUD operations
Database design documentation
